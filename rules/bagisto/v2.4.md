# Bagisto 2.4

The maintained release line.

| | |
|---|---|
| PHP | >=8.3 <8.5 |
| Laravel | v12 |
| Pest / PHPUnit | v3 / v11 |
| Tailwind CSS | v3 |
| Databases | MySQL, MariaDB |
| Packages in `packages/Webkul/` | 41 |

- Tailwind 3: sizes are arbitrary values such as `h-[38px]` and `w-[100px]`, not the v4 spacing scale.
- No PostgreSQL support — `db_grammar()` and its cross-database helpers do not exist. Plain `'like'` is safe here.
- Image processing goes through Intervention, configured in `config/image.php`.
- The e2e suites carry no package scripts: invoke `npx playwright test --config=tests/e2e-pw/playwright.config.ts` and `npx playwright install --with-deps chromium` directly, and note `playwright.config.ts` reads `APP_URL` only — CI's `BASE_URL` is ignored.
